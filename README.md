## Publish with GitHub Pages
1. Create a repository and upload the contents of this folder (keep `index.html` at the top level).
2. Settings, then Pages, then choose the main branch and the root folder.
3. The page appears at https://USERNAME.github.io/REPOSITORY/

The page carries a noindex tag, but GitHub Pages is public. Remove the site when you have finished showing it.
